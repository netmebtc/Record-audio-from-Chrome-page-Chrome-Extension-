# Spaces Recorder (Chrome Extension)

## 🧩 中文说明

### 功能

* 录制 Chrome浏览器的网页音频（例如X pace、Youtube）
* Start / Stop 控制
* 自动检测中断（共享断开自动停止）
* 低 CPU 占用，稳定运行

---

### 📦 安装方法（开发者模式）

1. 打开 Google Chrome
2. 在地址栏输入：

```
chrome://extensions/
```

3. 打开右上角 **“开发者模式”**
4. 点击 **“加载已解压的扩展程序”**
5. 选择本项目文件夹

---

### ▶️ 使用方法

1. 打开 X Spaces 页面
2. 点击浏览器右上角插件图标
3. 点击 **Start**
4. 在弹窗中勾选 **“共享音频”**
5. 录音过程中可随时点击 **Stop**
6. 音频会自动下载到本地

---

### ⚠️ 注意事项

* 必须勾选“共享音频”，否则没有声音
* 如果浏览器中断共享，录音会自动停止
* 文件格式为 `.webm`

---

## 🌍 English

### Features

* Record audio from Chrome page
* Start / Stop controls
* Auto-stop when audio sharing ends
* Low CPU usage

---

### 📦 Installation (Developer Mode)

1. Open Chrome
2. Go to:

```
chrome://extensions/
```

3. Enable **Developer Mode**
4. Click **Load unpacked**
5. Select this project folder

---

### ▶️ Usage

1. Open an X Spaces page
2. Click the extension icon
3. Click **Start**
4. Enable **Share audio**
5. Click **Stop** to save recording

---

### ⚠️ Notes

* Audio sharing must be enabled
* Recording stops if sharing is interrupted
* Output format is `.webm`
